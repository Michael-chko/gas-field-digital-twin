# Сверка прототипа с оригиналами статей (этап 12)

Пакет «Статьи_Газпром_2_БРИКС» от 26.10.2026: 64 PDF и реестр. Опись —
[`sources_inventory.md`](sources_inventory.md). До этой сессии числа «из источников» были взяты
через ТЗ и отчёт; теперь каждое сверено с оригиналом. Страницы — журнальные.

## Охват

- Все 64 файла: извлечён текст, составлена опись, по всем выполнен поиск порогов для открытых
  вопросов (П10, П14, П15, П16, пределы оснований, C5+, ЗПА).
- Построчно с кодом, конфигурацией и ТЗ сверены 20 статей, на которые прототип ссылается:
  Сафронова, Затырко, Долгов, Харионовский, Запевалов, Шевченко, Савченко, Печко, Григорьев,
  Поярков, Войтенков, Аксютин, Куник, Истомин, Прокопов, Соломахин, Семенова, Васин, Лобачев,
  Скоробогатова (2025).
- Остальные 44 файла просмотрены на предмет новых методов и рабочих диапазонов (раздел
  «Кандидаты на новые этапы»); большая часть — геология, шельф, бурение — к прототипу не относится.

## Итог в цифрах

- Исправлено расхождений в коде и конфигурации: 7 (единицы абсорбера, признак d200, подбор

## Реализовано по найденным формулам

**Срок безопасной эксплуатации** (Харионовский, Велиюлин, Городниченко, 2026, с. 191–197) —
`field_twin.safe_life`: t_сбэ = −ln(0,9)·1000 / (λ_пр·L_ср); λ_пр по коррозии (3) и с КРН (7);
повреждаемости (4)–(10). Тесты воспроизводят строки табл. 2 (например, № 1: λ = 0,1625, 6,9 года)
и табл. 3 (№ 1: λ = 0,4166, 2,5 года). Частоты отказов и выборки статьи — пример (Газпром трансгаз
Югорск); для проекта нужны свои данные ВТД. Срок пишется ручным вводом для П9.

**Гидравлика шлейфов** (Григорьев, Изюмченко, Гужов, Федулов, 2026, с. 209–214) —
`field_twin.hydraulics`: критериальное уравнение (1) (V* ≤ 1 — вынос жидкости, V* > 1 —
накопление), критическая скорость смеси при V* = 1 вместо диапазона 2…6 м/с, уравнение (2)
с адаптационными коэффициентами E и K. Область — 0,5–8 МПа. На условных свойствах фаз
критическая скорость ≈ 3,6–4,5 м/с. Свойства фаз и расход жидкости в АСУ не измеряются — нужны
PVT-расчёты; правило по критической скорости — кандидат на следующий этап.

## Расхождения внутри источников

- Харионовский и соавторы: текст (с. 194) требует округлять D_км/D_скм < 1 до 1, а табл. 2 и 3
  считают без этого (табл. 2, № 10: 0,843 → 0,1049). В коде — настройка `clamp_km`, по умолчанию
  как в тексте.
- Харионовский и соавторы, с. 195: для выборки с КРН подписано «D_скм = 0,043», по табл. 3 это
  D_скрн.
- Сафронова, с. 114: доля правильных 0,933 меньше, чем допускают точность 0,993 и полнота 0,961.
- Савченко и соавторы, рис. 1: давление 80–94 «10⁶ Па» — вероятно, бар.
