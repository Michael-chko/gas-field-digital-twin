# Цифровой двойник «месторождение + завод»: продольный разбор технологий по материалам ВНИИГАЗ

Полный текст — в документе проекта: https://claude.ai/artifact/5ttetctd7iramcmPh9pGtV
(инструмент выгрузки отдал его только во встроенном виде, без сохранения в файл; копию нужно
выгрузить в Markdown вручную и заменить этот файл).

Что из разбора используется в ТЗ:

- 9 звеньев цепочки «пласт → отгрузка» и 5 сквозных слоёв; материалы закрывают промысел,
  трубопроводы и ГПА, но не завод СПГ, аммиак и ЦОД.
- Принцип Сафроновой как шаблон для всего двойника: модель только советует, режим меняет человек,
  его решение возвращается в слой данных для дообучения (М7, М8).
- Стык с заводом — пять потоков: состав газа и остаток C5+; объём газа; раздельные потоки
  (с этаном и сухой); доступная мощность приводов; окна снабжения и ремонтов (М11).
- Остаток C5+ выше допуска завода — уведомление главному инженеру: тяжёлые компоненты
  вымерзают в теплообменниках сжижения (П16).
- Нужен обратный поток «завод → промысел»; в материалах его нет (М11, заглушка).
- Порядок внедрения: слой данных по СТО Газпром 2-3.3-1203-2020 и очистка → советчик по гидратам
  и метанолу → модель сети сбора → ресурс ГПА и геотехника → трубопроводы → заводской контур.
