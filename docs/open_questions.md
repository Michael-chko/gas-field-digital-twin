# Открытые вопросы: что сделано без ответа и что нужно от заказчика

Прототип работает без ответов на эти вопросы; где ответа нет, в коде стоит пустое значение
в конфигурации (правило выключено) или пометка «пример / условно».

| Вопрос (ТЗ, «Открытые вопросы») | Как сейчас в прототипе | Что нужно |
| --- | --- | --- |
| Ответы владельца АСУ ТП (Харасавэй: «Газпром добыча Надым», проектировщик): OPC UA, глубина архива, ИБ | Имитатор АСУ с OPC UA; шлюз только на чтение, с резервом и буфером | Перечень параметров с уставками, адрес и пространство имён сервера, учётная запись только на чтение, требования ИБ |
| Предельные значения оснований для конкретных сооружений | Примерные пределы в `config/tags.yaml` (`attrs.limits`), кроме 2 мм/м | Пределы по каждому пункту контроля |
| Правило оценки оснований по объекту в целом | Худший класс среди параметров | Подтвердить или дать правило |
| Порог П14 (корреляция связанных датчиков) | `min_pearson: null` — выключено; окно 2 ч | Значение порога |
| Порог П15 (ошибка моделей М4) | `max_error_pct: null` — выключено | Значение порога |
| Допуск завода по C5+ (П16) | `max_c5plus_g_m3: null` — выключено | Допуск от разработчика технологии сжижения |
| «Близко к нулю» для ЭХЗ (П10) | Срабатывает только при равенстве нулю | Допуск по току и потенциалу |
| Проценты в П7 (мощность −4 %, КПД −2 %) | Относительное снижение от начала межремонтного периода | Уточнить у производителя (относительные или абсолютные) |
| Допустимые диапазоны параметров (М2) | Только физические пределы по роли параметра | Диапазоны по параметрам (`ranges`) |
| Сглаживание давления (степень, порог, окно) | Выключено; проверено на 2 / 3σ / 12 точек | Параметры или подтверждение этих |
| Адресаты П2–П11 | Главный инженер (`configurable_recipient`) | Кому направлять |
| Формула критической скорости газа в шлейфе, коэффициенты E и K (Григорьев) | Не реализовано | Полный текст статьи |
| Формула срока безопасной эксплуатации газопровода (Харионовский) | Срок подаётся готовым числом | Полный текст методики |
| Обнаружение утечек по волнам разрежения (Лаптева) | Не реализовано | Полный текст диссертации |
| Размеченные реальные данные для М3 и М4 | Обучение на синтетике; путь обучения на разметке журнала готов | Архив АСУ с отметками периодов гидратов и решений |
| Матрица ошибок классификатора Сафроновой | Метрики статьи — только ориентир | Матрица ошибок от автора |
| Алгоритм подбора режима агрегатов | Связывающий алгоритм М4 без оптимизатора | Алгоритм (Чудин, АЭРОСИМ) |
| АЭРОСИМ: программный интерфейс, считает ли сжижение | Описанный пустой адаптер | Описание интерфейса, лицензия |
| tNavigator: лицензия и интерфейс | Описанный пустой адаптер | Условия лицензии |
| Применимость регрессий Савченко к газовым скважинам | М10 только ищет и размечает остановки | Проверка на данных газовых скважин |
| Расшифровка ЗПА у Чудина | Условно «здание переключающей арматуры» | Подтвердить |
| Измерение состава газа и C5+ на потоке | Поток `gas_composition` в словаре; в данных — синтетика | Есть ли поточный анализатор |
| Датчики шельфа (подводное оборудование, лёд, морские трубопроводы) | Не моделируется | Перечень датчиков и форматов |
| Телеметрия ЭХЗ вместо ручных замеров | Ручной ввод с пометкой и П11 | Решение о телеметрии |

Новое после подключения HYSYS:

| Вопрос | Как сейчас | Что нужно |
| --- | --- | --- |
