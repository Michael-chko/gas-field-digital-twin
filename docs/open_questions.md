# Открытые вопросы: что сделано без ответа и что нужно от заказчика

Прототип работает без ответов на эти вопросы; где ответа нет, в коде стоит пустое значение
в конфигурации (правило выключено) или пометка «пример / условно».

| Вопрос (ТЗ, «Открытые вопросы») | Как сейчас в прототипе | Что нужно |
| --- | --- | --- |
| Ответы владельца АСУ ТП (Харасавэй: «Газпром добыча Надым», проектировщик): OPC UA, глубина архива, ИБ | Имитатор АСУ с OPC UA; шлюз только на чтение, с резервом и буфером | Перечень параметров с уставками, адрес и пространство имён сервера, учётная запись только на чтение, требования ИБ |
| Предельные значения оснований для конкретных сооружений | Примерные пределы в `config/tags.yaml` (`attrs.limits`), кроме 2 мм/м. **Сверено (Затырко, с. 165–166):** в оригинале пределов по сооружениям нет — «установленные проектной, нормативной или иной документацией»; горизонтальное смещение — относительное ξ = ΔL/L (исправлено) | Пределы по каждому пункту контроля |
| Правило оценки оснований по объекту в целом | Худший класс среди параметров. **Сверено:** оценка «в целом для объекта» в статье выполнялась автоматически по критериям СП 22.13330.2016, само правило не раскрыто (с. 166) | Подтвердить или дать правило |
| Порог П14 (корреляция связанных датчиков) | `min_pearson: null` — выключено; окно 2 ч. **Сверено:** у Шевченко, Рычкова числа нет (с. 49–50). R ≥ 0,7 у Затырко (с. 166) — для верификации методов измерения по нивелированию, на П14 не переносится | Значение порога |
| Порог П15 (ошибка моделей М4) | `max_error_pct: null` — выключено. **Сверено:** у Григорьева и соавторов порога нет; 5 % у Касперовича и соавторов (2022, с. 199) — допуск секторной модели относительно полной, на П15 не переносится | Значение порога |
| Допуск завода по C5+ (П16) | `max_c5plus_g_m3: null` — выключено. **Сверено:** в пакете допуска нет («до 50 г/м³» у Громовой, Заночуева — содержание в пробах, не допуск) | Допуск от разработчика технологии сжижения |
| «Близко к нулю» для ЭХЗ (П10) | Срабатывает только при равенстве нулю. **Сверено:** в оригинале числа нет (Запевалов и соавторы, с. 79) | Допуск по току и потенциалу |
| Проценты в П7 (мощность −4 %, КПД −2 %) | **Частично закрыт (Поярков и соавторы, табл. 1, с. 165):** снижение «по сравнению с номинальными значениями» — отсчёт теперь от номинала 31,2 МВт и 36 %. Относительные или абсолютные проценты для КПД — в таблице не сказано, принято относительное | Уточнить у производителя только для КПД |
| Допустимые диапазоны параметров (М2) | Только физические пределы по роли параметра. У Савченко и соавторов (с. 149) фильтр давления «более 350×10⁶ и менее 10×10⁶ Па» — для нефтяных скважин с ТМС, не перенесён | Диапазоны по параметрам (`ranges`) |
| Сглаживание давления (степень, порог, окно) | **Параметры найдены (Савченко и соавторы, с. 149):** полином 5-й степени по всему периоду, абсолютный порог 0,5×10⁶ Па — внесены в `config/quality.yaml`, режим реализован. Выключено: статья о нефтяных скважинах, а шкала рис. 1 (80–94 «10⁶ Па») ставит под сомнение единицы | Подтвердить применимость к газовым скважинам и единицы порога |
| Адресаты П2–П11 | Главный инженер (`configurable_recipient`) | Кому направлять |
| Формула критической скорости газа в шлейфе, коэффициенты E и K (Григорьев) | **Закрыт:** уравнения (1) и (2) статьи реализованы в `field_twin.hydraulics` (с. 212–214). E и K — не константы, а адаптационные коэффициенты, определяются по данным промысла | Свойства фаз, расход жидкости и диаметры шлейфов; режимы выноса и накопления для подбора E и K |
| Формула срока безопасной эксплуатации газопровода (Харионовский) | **Закрыт:** формулы (1), (3)–(10) реализованы в `field_twin.safe_life`, тесты по табл. 2–3. Внутри статьи расхождение: в таблицах D_км/D_скм < 1 не нормируется, в тексте — нормируется до 1 (`clamp_km`) | Частоты отказов и данные ВТД своего общества; какое нормирование применять |
| Обнаружение утечек по волнам разрежения (Лаптева) | Не реализовано; в пакете автореферата Лаптевой нет | Полный текст диссертации |
| Размеченные реальные данные для М3 и М4 | Обучение на синтетике; путь обучения на разметке журнала готов | Архив АСУ с отметками периодов гидратов и решений |
| Матрица ошибок классификатора Сафроновой | Метрики статьи — только ориентир. **Сверено:** матрицы в оригинале нет (с. 114); доля правильных 0,933 при точности 0,993 и полноте 0,961 в оригинале действительно не сходится | Матрица ошибок от автора |
| Алгоритм подбора режима агрегатов | Связывающий алгоритм М4 без оптимизатора | Алгоритм (Чудин, АЭРОСИМ) |
| АЭРОСИМ: программный интерфейс, считает ли сжижение | Описанный пустой адаптер | Описание интерфейса, лицензия |
| tNavigator: лицензия и интерфейс | Описанный пустой адаптер | Условия лицензии |
| Применимость регрессий Савченко к газовым скважинам | М10 только ищет и размечает остановки | Проверка на данных газовых скважин |
| Расшифровка ЗПА у Чудина | Условно «здание переключающей арматуры». В пакете: Войтенков (2025, с. 135) — «запорно-перекрывающая арматура (ЗПА)»; Аксютин и соавторы — «пункт переключающей арматуры» (без сокращения). Диссертации Чудина в пакете нет | Подтвердить по тексту Чудина |
| Измерение состава газа и C5+ на потоке | Поток `gas_composition` в словаре; в данных — синтетика | Есть ли поточный анализатор |
| Датчики шельфа (подводное оборудование, лёд, морские трубопроводы) | Не моделируется | Перечень датчиков и форматов |
| Телеметрия ЭХЗ вместо ручных замеров | Ручной ввод с пометкой и П11 | Решение о телеметрии |
